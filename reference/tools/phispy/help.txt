# /opt/patric-common/runtime/bin/phispy --help
usage: phispy [-h] [-o OUTPUT_DIR] [-m MAKE_TRAINING_DATA] [-t TRAINING_SET]
              [-l {short,long}] [-p FILE_PREFIX] [-e [EVALUATE]] [-n NUMBER]
              [-u MIN_CONTIG_SIZE] [-w WINDOW_SIZE] [-g NONPROPHAGE_GENEGAPS]
              [--phage_genes PHAGE_GENES] [--metrics METRICS [METRICS ...]]
              [-r RANDOMFOREST_TREES] [--expand_slope]
              [--kmers_type {all,codon,simple}] [--phmms PHMMS]
              [--include_annotations | --ignore_annotations] [--color]
              [--threads THREADS] [--output_choice OUTPUT_CHOICE]
              [--include_all_repeats] [--keep_dropped_predictions]
              [--extra_dna EXTRA_DNA] [--min_repeat_len MIN_REPEAT_LEN]
              [--log LOG] [--quiet] [-k [KEEP]] [-v]
              [infile]

phiSpy is a program for identifying prophages from among microbial genome
sequences

positional arguments:
  infile                Input file in genbank format

options:
  -h, --help            show this help message and exit
  -o OUTPUT_DIR, --output_dir OUTPUT_DIR
                        The output directory to write the results
  -m MAKE_TRAINING_DATA, --make_training_data MAKE_TRAINING_DATA
                        Create training data from a set of annotated genome
                        files. Requires is_phage=1 qualifier in prophage's
                        CDSs
  -t TRAINING_SET, --training_set TRAINING_SET
                        Choose the most closely related set to your genome.
                        [Default data/trainSet_genericAll.txt]
  -l {short,long}, --list {short,long}
                        List the available training sets in one of the formats
                        [short, long] and exit.
  -p FILE_PREFIX, --file_prefix FILE_PREFIX
                        An optional prefix to prepend to all of the output
                        files
  -e [EVALUATE], --evaluate [EVALUATE]
                        Run in evaluation mode -- does not generate new data,
                        but reruns the evaluation
  -n NUMBER, --number NUMBER
                        Number of consecutive genes in a region of window size
                        that must be prophage genes to be called. [Default: 5]
  -u MIN_CONTIG_SIZE, --min_contig_size MIN_CONTIG_SIZE
                        Minimum contig size (in bp) to be included in the
                        analysis. Smaller contigs will be dropped. [Default:
                        5000]
  -w WINDOW_SIZE, --window_size WINDOW_SIZE
                        Window size of consecutive genes to look through to
                        find phages. [Default: 30]
  -g NONPROPHAGE_GENEGAPS, --nonprophage_genegaps NONPROPHAGE_GENEGAPS
                        The number of non phage genes betweeen prophages.
                        [Default: 10]
  --phage_genes PHAGE_GENES
                        The minimum number of genes that must be identified as
                        belonging to a phage for the region to be included.
                        The default is 1 or more genes.
  --metrics METRICS [METRICS ...]
                        The set of metrics to consider during classification.
                        If not set, all metrics (orf_length_med,
                        shannon_slope, at_skew, gc_skew, max_direction) will
                        be considered.
  -r RANDOMFOREST_TREES, --randomforest_trees RANDOMFOREST_TREES
                        Number of trees generated by Random Forest classifier.
                        [Default: 500]
  --expand_slope        Use the product of the slope of the Shannon scores in
                        making test sets
  --kmers_type {all,codon,simple}
                        Type of kmers used for calculating Shannon scores.
                        [Default: all]
  --phmms PHMMS         Phage HMM profile database (like pVOGs) will be mapped
                        against the genome of interest and used as additional
                        feature to identify prophages. Note that this is
                        experimental at the moment
  --include_annotations
                        Use the annotations in the GenBank file in the phage
                        predictions (default)
  --ignore_annotations  Ignore the annotations in the GenBank file during
                        predictions
  --color               If set, within the output GenBank file CDSs with phmms
                        hits will be colored (for viewing in Artemis).
  --threads THREADS     Number of threads to use while searching with phmms
                        and the random forest. [default: 2]
  --output_choice OUTPUT_CHOICE
                        Sum of codes for files to output. For more details see
                        the README.md file at
                        https://github.com/linsalrob/PhiSpy#choosing-which-
                        output-files-are-created. [default: 3]
  --include_all_repeats
                        include all repeats in the genbank output
  --keep_dropped_predictions
                        Write regions that might be prophages to the output
                        files
  --extra_dna EXTRA_DNA
                        additional DNA flanking the predicted prophage to test
                        for repeats [Default 2000]
  --min_repeat_len MIN_REPEAT_LEN
                        minimum repeat length to search for [Default: 10]
  --log LOG             Name of the log file to write details to [Default:
                        phispy.log]
  --quiet               Run in quiet mode
  -k [KEEP], --keep [KEEP]
                        Do not delete temp files
  -v, --version         show program's version number and exit
